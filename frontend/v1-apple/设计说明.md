# Scorebook 前端原型 · 设计说明

文件：`index.html`（可直接发布为 Artifact 的页面主体）；`local.html`（带 doctype 的本地可双击打开版本）。纯 HTML/CSS/JS，无构建步骤，示例数据均为虚构。

## 视觉基调

- 浅色、留白、系统字体（-apple-system / PingFang SC，Inter 作 Web 回退），等宽字体只用于记录编号与价格。
- 色板：底 `#f5f5f7`，侧栏 `#ededf0`，卡片 `#fff`，文字 `#1d1d1f / #6e6e73 / #a1a1a6`，强调 `#0071e3`（深色 `#0a84ff`）。
- 语义色与强调色分开：兑现 `#1f9d8a`、未兑现 `#e8604b`、观察中 `#5e5ce6`、未触发 灰、未设口径 描边、数据不足 斜纹。
- 口径 chip 统一琥珀色（`#fdf3df / #8a5a00`），在结果卡、判断卡、采集面板三处外观一致。
- 三态主题：`:root` 浅色为基准，`prefers-color-scheme: dark` 与 `data-theme` 双重覆盖；截图与标准图不随主题变化。

## 信息架构

侧栏四个入口对应三条流程：找回（记录的入口按钮常驻）、复盘（到期待复盘 / 待处理 / 裁决）、情境档案、打法版本；设置放底部。运维、审计、规则版本等技术信息一律折叠进判断卡底部的「技术详情」。

## 面向交易员的功能体验

- **记录**：⌃⇧S 唤起浮层；截图缩略、品种与默认口径在输入前就可见；原话即时解析出方向 / 期限 / 阈值 / 失效价 / 标签，识别不到就按原话保存（T0）；中文输入法组字时回车不提交；保存后立刻给出编号与到期时间，可补充或撤回；演示条可切换「无现场图」「品种未识别」两种降级状态。
- **找回**：⌘K 聚焦搜索；结果筛选始终可见；只按时间倒序；同一段行情的记录用轻带归组；j / k / Enter 键盘走查。
- **判断卡**：原图 / 前图 / 后图 / 补图分段切换（← →），每张图带身份与数据截至时间；右栏按「市场怎么回答 → 实际行动（未接入）→ 回看 → 打法」排列；null 一律显示为「—」；归组建议、品种确认在卡内直接处理。
- **复盘**：队列按行情段分组；右侧原图 + 后图对照；三个执行选项 + 回看文字 + 改法输入，改法保存即成为候选版本；K / R 快捷键。
- **情境档案**：没有总分与排名；大数字可点开成员；六态条按类别展开；同期市场背景只在方向到期类口径下出现；Wilson 区间折叠。
- **打法版本**：时间线倒序，候选可一键采用，采用不改动已有结果；计划采用的判断标「执行：未知」。

## 键盘

⌃⇧S 记录 · ⌘K 搜索 · Esc 关闭 · 找回页 j/k/Enter · 判断卡 ←/→ 切图 · 复盘页 j/k 切条、K 沿用、R 保存。
