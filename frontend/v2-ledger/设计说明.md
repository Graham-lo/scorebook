# Scorebook 记分簿 · 前端设计说明（v2）

面向交易员的判断账簿。这一版彻底放弃了上一版的「苹果风」，也不走深色工程风：
它是一本**账簿**——纸色底、蓝墨字、印章式结果、荧光笔口径。

## 视觉语言

| 要素 | 处理 |
|---|---|
| 底色 | 冷灰绿的纸色 `#e9ede7`，纸页 `#fbfcf9`；夜间模式为深墨绿 `#131614` / `#1b1f1d` |
| 字体 | 标题与原话用衬线 Instrument Serif / Noto Serif SC；正文 IBM Plex Sans / Noto Sans SC；编号 IBM Plex Mono |
| 强调色 | 一种蓝墨 `#1f4e9c`，只用在导航、主按钮、当前项 |
| 结果状态 | **印章**：兑现（绿）、未兑现（红）微微倾斜 −2°；观察中虚线框；未触发点线框；未设口径细线；数据不足斜纹底 |
| 评价口径 | **荧光笔**高亮一行：`偏多 · 72 小时 · 失效 61,500  阈值 1×ATR14 ≈ 2.1%` |
| 卡片 | 1px 线 + 极浅阴影，不堆叠圆角；只在浮层和表单上用抬升阴影 |
| 三态主题 | `:root` 浅色 / `prefers-color-scheme: dark` / `data-theme` 手动，所有颜色走 token |

## 页面与交互（全部可操作）

**找回（Recall）**
- 顶部周账条：本周记录 / 到期待复盘 / 需要补一句 / 情境待裁决，各自点进去直达。
- 账页式列表：日期列（大号日、月、时刻）· 原图 · 原话 + 口径 + 标签 · 结果印章。
- 搜索只刷新列表，不打断输入；命中词用 `<mark>` 高亮；中文输入法组字期间不触发。
- 筛选：结果（多选，选中后显眼的蓝色 chip）、品种、表态、标签；只按时间排序；可切换「按行情段」分组。
- 键盘：`/` 聚焦搜索，`J/K` 移动，`Enter` 打开。

**判断卡（Call）**
- 三种看图：原图（点开放大，带记录时刻）/ 系统图 / 前后对照；三者身份不混淆，缺原图时明确说「系统图不能替代原图」。
- 口径用白话一句话讲清「这条会怎么被评价」，下方规则逐行列出，口径锁定提示。
- 结果区：大印章 + 一句解释 + 到期涨跌 / 最有利 / 最不利 / 首次达标。
- 情境链：同段判断串成一条线，建议归入的节点用虚线点，可在卡上直接「归入 / 不是一段」。
- 更多：复制原话、添加补图、从行情段移出；「技术详情」折叠了编号、口径版本、行情源等。
- 键盘：`←/→` 上下一条（沿当前筛选顺序），`Backspace` 返回。

**复盘（Review）**
- 左队列：到期待复盘 / 需要你补一句 / 情境待裁决 / 本次已完成，底部进度条。
- 右面板一次只看一条：原图与到期后系统图并排，原话，印章，一句话解释。
- 回答「和预期一样吗」三选一（`1/2/3`），一句备注，一句改法——改法会自动进入打法作为候选版本。
- 补一句：品种待确认（直接选品种，立即按原口径开始评价）、归组建议（看链条后归入或拒绝）、缺现场图（补图会标为「补图」）。
- 裁决：继续用 / 改了再用 / 先停用 + 理由；给出置信区间与无条件基准，但明确写「这不是分数」。
- 键盘：`J/K` 切换，`⌘↩` 保存并下一条。

**情境档案（Archive）**
- 左侧标签列表带待办小圆点；右侧：口径荧光笔、四个大数（点击可筛成员）、六态色带 + 图例（点击筛选）、到期涨跌分布、「这个情境在教你什么」（只把数字念出来）。
- 待裁决 / 需复查 / 待确认归组三种提示各有直达按钮。
- 成员列表可直接点进判断卡；无打法时可一键「为它建打法」。

**打法版本（Playbook）**
- 版本时间线：现行实心、候选虚线、历史/撤回淡出；每版记录改了什么 / 原来 / 依据 / 期望 / 代价 / 撤回原因 / 采纳后的样本。
- 候选可「采纳为现行」或「撤回（需写原因）」；「提新版本」表单先存为候选；可新建打法。

**记录判断（采集浮层，⌃⇧S）**
- 顶部：现场缩略图 + 品种（可换）+ 窗口来源 + 实时生成的口径白话句。
- 横线稿纸风的输入区，边写边解析：表态 / 期限 / 阈值 / 失效 / 模板 / 标签；识别不出方向时提示「按不设口径保存」。
- 快捷段控：表态、期限；「更多口径」展开阈值、失效价、标签。
- 输入法组字中回车不提交，页脚有状态灯；保存后盖「已入账」印章，可直接打开判断卡或再记一条。
- 演示场景切换：正常 / 品种未识别 / 无截图，分别产生对应的「补一句」待办。

## 硬约束（沿用计划书）
不显示总分、排名、连胜；空值一律「—」不显示 0；结果卡必有原图 + 原话 + 记录时刻；原图 / 系统图 / 补图身份清楚；结果筛选可见；只按时间排序；规则版本等折叠进「技术详情」；前端不计算业务结果（示例数据即后端返回值）。
