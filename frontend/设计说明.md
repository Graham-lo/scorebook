# Scorebook 记分簿 · 前端设计说明（v3 记分牌）

面向交易员的判断账簿。这一版既不是苹果风，也不是深色工程风，更不是上一版安静的纸账簿：
它的原型是**球场边的记分牌**——一条恒定的深靛蓝牌面横在页顶，黄铜色的灯亮在牌上，
六种结果状态各是一盏信号灯，翻页、开灯、点数、画线都有动作。

## 视觉语言

| 要素 | 处理 |
|---|---|
| 底色 | 冷瓷灰 `#e8e9f2` / `#dedfec`，纸页 `#fdfdff`；夜间为深夜蓝 `#0c0d1c` / `#171930` |
| 牌面 | 顶栏是常驻的深靛蓝牌 `#151732`，浅色夜色两种主题下都保持深色，像真的记分牌 |
| 强调色 | 一种黄铜金 `#c08d1c`（夜间 `#e8bb5c`），只用在牌上的灯、当前项、主按钮 |
| 字体 | 标题与原话用 Newsreader 衬线（配 Noto Serif SC）；正文 Archivo 可变宽字；数字与编号 DM Mono |
| 结果状态 | **信号灯**：每个状态前一颗会发光的圆点。兑现绿、未兑现红、待定蓝且呼吸闪烁、未触发与未设口径灰、数据不足叠斜纹 |
| 评价口径 | 荧光条高亮一整行：`偏多 · 72 小时 · 失效 61,500  阈值 1×ATR14 ≈ 2.1%` |
| 氛围 | 页面底层有一层缓慢漂移的光晕（46 秒一循环）加极细颗粒，不抢内容，只让底不死 |
| 层次 | 边框、填充、圆角、阴影按角色分配，不是每块都套同一个圆角加同一层阴影 |
| 三态主题 | `:root` 浅色 / `prefers-color-scheme: dark` / `data-theme` 手动，所有颜色走 token |

## 动效系统

这一版把动效当成设计的一部分，而不是点缀。全部动作都尊重 `prefers-reduced-motion: reduce`，
开了减少动效就整页静止。

- **入场错峰**：页面主块、账页行、队列项、标签行、统计卡依次上浮，带一点点散焦收敛，每项相隔 34–46 毫秒。
- **导航滑块**：顶栏当前页的高亮块用 FLIP 方式测量实际位置，在标签之间滑过去，而不是硬切。
- **数字滚动**：周账条、大数、六态腿的数值从 0 滚到目标值，700 毫秒缓出，结束后还原原本的排版（含单位与「—」）。
- **图表画线**：所有折线图用 `getTotalLength` 计算路径长度，靠 `stroke-dashoffset` 一秒钟画出来，延后 120 毫秒起笔。
- **灯与呼吸**：牌上的字标旁有一盏脉冲的黄铜灯；「观察中」状态的信号灯持续呼吸。
- **按压反馈**：可点的行、卡、选项按下时缩到 0.994，松开回弹。
- **浮层编排**：采集浮层与放大看图各有自己的进场曲线，保存成功后盖章，然后账页里对应的那一行会被金色标记闪一下（1.7 秒后自动褪去）。

## 页面与交互（全部可操作）

**找回（Recall）**
- 顶部周账条：本周记录 / 到期待复盘 / 需要补一句 / 情境待裁决，数字滚动进场，各自点进去直达。
- 账页式列表：日期列（大号日、月、时刻）· 原图 · 原话 + 口径 + 标签 · 结果信号灯。
- 搜索只刷新列表，不打断输入；命中词高亮；中文输入法组字期间不触发。
- 筛选：结果（多选，选中后是显眼的金色 chip）、品种、表态、标签；只按时间排序；可切换「按行情段」分组。
- 键盘：`/` 聚焦搜索，`J/K` 移动，`Enter` 打开。

**判断卡（Call）**
- 三种看图：原图（点开放大，带记录时刻）/ 系统图 / 前后对照；三者身份不混淆，缺原图时明确说「系统图不能替代原图」。
- 口径用白话一句话讲清「这条会怎么被评价」，下方规则逐行列出，口径锁定提示。
- 结果区：大号信号灯 + 一句解释 + 到期涨跌 / 最有利 / 最不利 / 首次达标。
- 情境链：同段判断串成一条线，建议归入的节点用虚线点，可在卡上直接「归入 / 不是一段」。
- 更多：复制原话、添加补图、从行情段移出；「技术详情」折叠了编号、口径版本、行情源等。
- 键盘：`←/→` 上下一条（沿当前筛选顺序），`Backspace` 返回。

**复盘（Review）**
- 左队列：到期待复盘 / 需要你补一句 / 情境待裁决 / 本次已完成，底部进度条随处理推进。
- 右面板一次只看一条：原图与到期后系统图并排，原话，信号灯，一句话解释。
- 回答「和预期一样吗」三选一（`1/2/3`），一句备注，一句改法——改法会自动进入打法作为候选版本。
- 补一句：品种待确认（直接选品种，立即按原口径开始评价）、归组建议（看链条后归入或拒绝）、缺现场图（补图会标为「补图」）。
- 裁决：继续用 / 改了再用 / 先停用 + 理由；给出置信区间与无条件基准，但明确写「这不是分数」。
- 键盘：`J/K` 切换，`⌘↩` 保存并下一条。

**情境档案（Archive）**
- 左侧标签列表带待办小圆点；右侧：口径荧光条、四个大数（点击可筛成员）、六态色带 + 图例（点击筛选）、到期涨跌分布、「这个情境在教你什么」（只把数字念出来）。
- 待裁决 / 需复查 / 待确认归组三种提示各有直达按钮。
- 成员列表可直接点进判断卡；无打法时可一键「为它建打法」。

**打法版本（Playbook）**
- 版本时间线：现行实心、候选虚线、历史与撤回淡出；每版记录改了什么 / 原来 / 依据 / 期望 / 代价 / 撤回原因 / 采纳后的样本。
- 候选可「采纳为现行」或「撤回（需写原因）」；「提新版本」表单先存为候选；可新建打法。

**记录判断（采集浮层，⌃⇧S）**
- 顶部：现场缩略图 + 品种（可换）+ 窗口来源 + 实时生成的口径白话句。
- 输入区边写边解析：表态 / 期限 / 阈值 / 失效 / 模板 / 标签；识别不出方向时提示「按不设口径保存」。
- 快捷段控：表态、期限；「更多口径」展开阈值、失效价、标签。
- 输入法组字中回车不提交，页脚有状态灯；保存后盖「已入账」章，可直接打开判断卡或再记一条。
- 浮层下方是一条独立的半透明胶囊条，用来切换演示场景：正常 / 品种未识别 / 无截图，分别产生对应的「补一句」待办。

## 硬约束（沿用计划书）
不显示总分、排名、连胜；空值一律「—」不显示 0；结果卡必有原图 + 原话 + 记录时刻；原图 / 系统图 / 补图身份清楚；结果筛选可见；只按时间排序；规则版本等折叠进「技术详情」；前端不计算业务结果（示例数据即后端返回值）。
默认口径同计划书：加密 72 小时、美股 3 个交易日、1×ATR14、T3 一分钟收盘触发、T5 k=1.5、行情段窗口 120 小时或 5 个交易日、裁决门槛 20 个情节、周报周日 18:00。
