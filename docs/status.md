- 真实币安小范围验证：BTCUSDT、1h、96 根已完成 K 线，建立 3 个窗口 × 2 个模型，共 6 条特征；内存 SVG 的 XML 解析通过。详见 [实际结果](live-smoke-result.json)。这是数据链路验证，不是检索准确率验收。

## 尚未完成

1. **没有建立币安全量历史索引。** 本地只保留上述小范围开发索引。API 搜索范围明确为已就绪的索引；覆盖清单分页返回，不能把一次搜索描述成“全部历史已搜索”。
2. 全量索引的自动发现、分片调度、持续增量、合约退市清单、预算和全局限流尚未实现。现在可通过多个有界任务分段建库。
3. 真实截图的自动图表裁剪、周期/根数识别、跨配色及缩放鲁棒性、结构精排和标注集准确率验收尚未完成。DINOv2 是通用视觉基线；相似度不等于走势胜率。
4. 查询当前采用过滤后的精确向量检索。虽已建 HNSW 索引，但尚未启用并验证大规模 ANN 检索；不能承诺全历史低延迟。
5. T3 条件触发的真实行情持续监测尚未接通；返回证据不足。其他自动评价的逐笔边界与各种合约缺口还需真实验收。缺日线覆盖不计算自动 ATR。正式统计、B1 基线、完整裁决和数据订正流程仍未验收。
6. Chat 界面、模型意图理解/自动调度、交易所私有 API 导入、Telegram 与周报不在本轮已完成范围。当前模型工具可读取数据；批量建立索引仍通过后台写接口提交，未暴露成只读工具。
7. 公网用户登录、对象存储、跨进程限流、公平调度、生产备份演练、持续负载/崩溃恢复测试尚未完成。本地服务没有安装自动启动。
8. 查询截图目前会保存为用户附件；查询图 TTL 与孤立文件定期回收尚未实现。长期高频使用前应补上清理策略。

## 数据保存约定

保存用户上传的截图、文字、复盘、版本、向量、窗口坐标、摘要和查询结果定位信息。不保存从币安取得的原始 K 线、逐笔行情和系统生成图。检索命中后按坐标重新获取并绘图。

因此导出可以校验用户附件和新评价元数据摘要，但不能离线重放未保留的行情输入。迁移时移除原始行情的旧元数据单独统计为 `legacy_redacted_manifests`，不宣称摘要已验证。供应商历史修订可能使重新取得的行情与建立索引时不同。
