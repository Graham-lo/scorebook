## 验证证据

- 24 个领域测试、30 个 PostgreSQL 集成测试、1 个真实本地视觉测试；其中新增数据库共享搜索容量限制、并发草稿与结果发布、放弃草稿的迟到请求、结果变化确认、2,000 条未发布检查点剔除、导出/恢复发布中断等验证。Clippy、格式和包边界检查通过。
- `acceptance-v3.json`：本轮中间版本的 30 分钟混合读取/草稿保存，55,915 次读取、888 次保存，异常请求 0；API/worker 被终止并重启后草稿保留。该报告记录具体 release SHA；后续队列投影和检索调整另有针对性验证，不能把这次计时说成最终二进制的全量长时验收。
- 同一报告：10 万合成记录、20 并发，列表/常见文字/罕见文字/零匹配/单汉字零匹配分别测量；P95 约 14–30 ms。
- 同一报告：1,200,035 行逻辑导出及文件校验约 14.4 秒，worker RSS 增长 4,997,120 字节。基准中的百万行是合成事件，不是行情或用户内容。
- `review-queue-acceptance-v3.json`：最终队列投影，10 万记录、20 并发，待复盘/草稿/已完成/稍后处理 P95 约 26/8/10/7 ms。少量草稿、复盘和提醒特意放在最旧记录上。
- `private-ann-plan-v3.json`：2 万合成私有图片，实际关联/过滤/去重 SQL 选择 HNSW，该次执行约 81 ms、精确对照 Recall@20=1；只覆盖一个合成租户和一个查询，不能外推为所有租户的百万级结果。
- `vision-acceptance-v3.json`：本地编码器 2 并发 40 次，P95 约 64 ms；8 图批量约 216 ms。权重身份和批/单图向量一致性通过，旧 /embed 路径为 404。这是编码器测试，不含上传与数据库检索。
- `ann-acceptance-v3.json`：百万条 192 维合成公共向量，40 组不同结构分别测不筛选/10% 品种筛选，80 个查询的平均 Recall@20 为 **96.69%**（两组分别 96.75%/96.62%，最低 85%）；实际查询选择 HNSW。8 并发、160 次 SQL 查询 P95 **1,632 ms**，不含编码与 HTTP。这是候选排序与扫描预算的质量/耗时取舍，不是全量无遗漏保证。
- 初测失败保留在 `ann-baseline-v3.json` 和 `ann-filter-baseline-v3.json`；后者的品种筛选平均召回仅 33.63%。`ann-initial-tuning-v3.json` 的查询落在同一合成簇，不能作为全面验收。最终使用 relaxed_order、物化重排和扩大后的有界扫描预算，没有运行时精确检索降级。
- `acceptance-final-smoke-v3.json`：最终候选二进制的 60 秒混合负载和受控重启补充回归，错误 0，草稿恢复；10 万记录/20 并发常用读取 P95 约 8–16 ms，1,200,033 行导出约 12.95 秒，RSS 增长 4,014,080 字节。报告记录具体二进制 SHA。

以上都是本机合成容量或功能回归，未清空操作系统缓存；不能称为冷盘或生产 SLO 保证。200 张真实 K 线的人工语义标注和目标生产环境 2 小时验收尚未完成。
