## 不保留旧 fallback

已核对 `~/.codex/memories/MEMORY.md` 第 8 节“不保留隐藏 legacy fallback”，并采用用户更严格的本轮要求。仅参考架构原则，未沿用其他项目的 VPS/部署配置。

旧 src/application、src/adapters、src/domain、src/http 已迁入唯一 workspace 实现；旧 spot 适配、history_windows 运行查询、单图 /embed、v1 归档宽松校验等路径移除。混合检索缺一模型明确失败，精确向量检索仅用于测试对照。重试/进程恢复继续执行同一新版协议，归档恢复需要同一校验身份，不伪装成功。

## 长期复盘

草稿时钟跨发布/丢弃保持单调，原判断 revision 与提醒 revision 独立。发布核对用户实际看到的 outcome IDs，冲突保留内容。正式复盘关联当时结果，历史分页保留稳定锚点。队列状态在同一业务事务内维护，可以从源表整体重建，不把用户请求变成遍历全部历史的计算。

前端没有在本轮修改。体验规范和 Claude Prompt 已按真实接口更新，交易员页面不应展示审计或运维字段。

## 部署

主库由迁移 5 升至当前版本，升级前保留数据库和原图备份。旧手动 API/worker/vision 已退出；本机使用同一 release 的用户级服务。原始记录/原图数量未变化，真实 v2 归档校验通过。数据库容器已重建并保留持久卷，1GB 共享内存配置已生效。独立百万向量验收库在测试结束后移除，保留的均为结果报告。
