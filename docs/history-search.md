# 按图查找历史走势

两种搜索范围共用图像编码基础，但数据身份独立：个人库只返回当前用户的原图和记录；公共行情库只保存由币安合约数据计算的特征、模型版本、输入哈希与时间坐标。

## 数据和模型

- 用户上传原图保留原字节。`scene` 原始现场图用于案例检索；后补/参考图不自动冒充现场证据；`query` 查询图默认临时保留。
- `candle-profile-v1`：192 维蜡烛区域结构描述子，有配色与区域限制。`dinov2-small-v1`：固定版本本地 DINOv2 384 维，letterbox 224、CLS+L2。不同模型空间不混用。
- `hybrid-v1`：个人库两路独立检索后 RRF 融合，两路均为必需。缺任何一路明确失败，不自动降级。
- 历史库一次明确选择一个模型。ANN 候选预算 3,000，物化后按距离重排，前 1,000 个按半个窗口间隔去重；结果是近似的相似结构，不是行情预测概率。

## 构建范围

单次索引 `/v1/history/indexes` 最多 50,000 根来源 K 线、1,000 个窗口、2 个模型。窗口 32–256 根，周期支持 1m/5m/15m/1h/4h/1d。每块 500 行写入，计算时最多 8 图一批。数据未准备完成时不发布该代；恢复后仅发布当前有效的窗口集合，弃用的旧检查点不会混入结果。

长范围使用 `/v1/history/plans`，显式指定合约列表（最多 200）、周期（最多 6）、日期、窗口、步长和模型。每个计划最多一个未完成子区间，每段最多 512 个窗口起点。暂停会使旧执行者失去发布资格；恢复保留子任务和进度，从新代继续。

`GET /v1/history/coverage` 分页列出公共已发布覆盖，支持 symbol/market/interval/model_id/cutoff_at。`GET /v1/history/indexes` 列出当前用户发起的任务，不等于公共总覆盖。搜索响应最多附带 100 段覆盖摘要，全面解释范围时必须继续查询覆盖接口。

不能把范围声明成“币安全部历史已经索引”。币安可提供的品种、上线时间、周期和请求限制不同；历史计划只有在逐段完成后才扩大已发布覆盖。股票相关品种也是实际存在的币安合约，不能当作美股现货全市场。

## 搜索和重绘

1. 上传截图为 query，选择原图像素坐标区域。
2. 个人库调用 `/v1/similarity/search`；历史库调用 `/v1/history/search`。
3. 结果保留模型/语料版本、截断时间、输入质量和范围说明。按 source_uri 跳回记录或时间窗口。
4. 历史命中附 chart_request，用 `/v1/market/chart` 再取币安数据并返回 SVG。系统图与原始行情只留在内存中；前端也不得持久缓存。
5. 可显式保存检索会话；模型只读工具计算不落搜索会话和临时 embedding。

供应商订正后再次重绘可能与当时索引输入不同，结果附索引时 input hash，不能承诺永远像素一致。当前没有存储逐字节原始行情，导出不能提供这种离线市场重放。

## 实际验收

本地模型连通和跨主题图像检索有回归测试；HNSW 计划/合成向量召回和并发结果见对应 JSON 验收报告。合成向量召回衡量近似检索与精确距离排序的一致程度，不证明真实 K 线语义匹配质量。200 张真实图的人工标注评审仍需另行准备语料。
