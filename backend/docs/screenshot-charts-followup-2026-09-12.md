# 截图复用、全屏图表与视觉升级验收

更新时间：2026-09-12T20:49:20+08:00。这是 2026-09-12 后续交付，优先于同目录早期 verification 文档的旧产物与测试数量。

## 最终行为

- 上传 scene / reference / supplement / query 均自动尝试定位。高置信且唯一的结果永久保存；再次打开直接读取坐标并画真实 K 线。存在歧义时展示候选供确认，无法对应时才显示手动校准。读取状态不会启动 OCR，也不会因浏览或重复上传而重跑失败的自动任务。
- 同一账户按文件内容去重，文件名不影响结果。浏览器先比对内容减少重复传输，服务端 SHA-256 校验并串行合并并发请求。同用途相同内容复用附件 ID；不同用途保留各自元数据，共享定位、OCR 和相同裁剪/模型的图像特征。人工校准同步至内容相同的附件；自动作业不会覆盖已确认位置。文件重新压缩或内容改变时不作模糊合并，避免误删不同证据。
- 上传去重在取得写事务前预留轻量清理记录，避免大量重复请求占满连接池后再等待第二个连接。重复预留记录在同一事务中删除；失败上传仍可由原有 GC 回收。永久定位及待确认的 K 线图不因临时查询图 24 小时清理而丢失。
- 记录、上传预览、复盘附件、搜索图和重温图统一进入真实走势。全屏按钮位于右上角；使用 TradingView Lightweight Charts 5.2.1，支持十字线 OHLC/成交量、鼠标拖动缩放、触摸缩放、价格轴操作、复位。浏览器原生全屏不可用时铺满视口，Esc 先退出全屏、再关闭。不是完整的 TradingView 网站或其全部工具功能。
- 相似历史结果整张卡片可点，展示真实 K 线，可在结果间切换并查看后续 32/64/128 根。橙色虚线优先读取截图永久定位对应的真实收盘价；未定位时提取主图轮廓。只作线性时间/幅度缩放，不作动态扭曲；后续行情不参与叠加归一化或搜索得分。蓝色截止线区分匹配区间与真实后续；对比图内不贴原截图。
- 浏览器截图排除地址栏/标签和右侧自选列表，按主图价格轴裁出轮廓区域。验收中发现原测试图主图为黄金，浏览器标签却写 HYPE；修正后不会继续认成 HYPE。不在当前行情目录的品种保持未确定，不能假装已对应币安行情。
- 视觉统一为石墨灰与薄荷绿，重做首页层级、导航、字体、留白、搜索大图卡与图表工作区；保留浅色偏好、移动底栏和减少动效设置。
