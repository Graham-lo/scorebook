# 按截图找公开历史相似走势：2026-09-13

用户明确要求：公开库找相似；60% 指结构相似度。不是在自己的复盘记录里查找，也不是自动确认截图原始位置。

## 根因与修复

1. 旧实现的 `calibration::level` 在某个周期/长度档满 500 个样本后，从绝对分自动切换成稀有度百分位。真实黄金查询最高结构分 0.6939，但稀有度 0.332，因此全部被隐藏。现在公开检索始终按最终结构分 >= 0.60 展示，边界包含 0.60；等级也只来自结构分。旧校准样本保留供审计，后台校准作业结束为 retired，不再继续下载计算或混入新召回算法的数据。私库保持原有展示规则。
2. SKHY 原图顶部红绿文字的两个碎片被连通域当作蜡烛，造成假尖峰，检测框从原图 y=351 开始。新增通用周期栏边界：同一行至少三个不同的周期文字才建立边界，整条工具栏以上不参与蜡烛检测，保持检测缩放不变。修复后检测框从 y=801 开始，110 根有效几何；移除顶部干扰也使此前被其占位的两根真实蜡烛重新进入结果。
3. 旧召回只比较整个固定长度窗口的余弦距离，先取 3000 再截 1000，之后才允许 ±15% 变长精排。SKHY 正确原始片段被包含在某个 128 根索引窗口中，但它的全窗向量排到 4021，被提前漏掉；关闭 ANN 索引做精确向量扫描仍复现。现在先取有界的 10000 个公开特征，再从既有 192 维描述符的中心和幅度通道做局部对齐排序，随后进行每合约去重及最多 300 窗口真实 OHLC 精排。结构分仍完全来自真实行情的 DTW，来源证明、哈希核对、缺失排除不变。跨品种查询在候选阶段先限定 USDT 报价，避免其他报价耗费名额。
4. 品种识别原来只有完整合约名等值匹配。新增公开搜索建议：XAUUSD 的基础资产 XAU 通过 Binance 商品目录的精确 baseAsset 匹配到 XAUUSDT；不会匹配到 XAUTUSDT。响应另外保留 source_symbol=XAUUSD、symbol_from=catalog_base_asset。定位锚点不把这个跨报价建议当成精确来源。
5. Binance 实时目录把黄金、SKHY 等标记为 TRADIFI_PERPETUAL，不能只认 PERPETUAL。基础资产建议和跨报价去重均支持这两类；公开候选的报价筛选不再排除传统资产。分析缓存的身份包含当前识别证据和几何，目录刷新后不会继续返回此前的空识别，旧分析记录保持原样。
6. 周期解析原来要求数字前缀，漏掉 TradingView 高亮的“天”。现在支持独立中文日/天、周/週、月；原生 OCR 根据已识别的周期行做局部放大补读。低置信单字需要主图标题中的同周期文字和明确的选中样式共同支持；未选中/相互矛盾仍不自动选。OCR 缓存协议更新到 native-ocr-toolbar-v3，分析结果版本更新到 toolbar-chart-boundary-v6。

7. 日线实测发现原精排无条件向后扩展 L/4 根，近期 192 根日线候选会请求尚未到来的日期，触发 invalid_archive_range 并终止整次搜索。扩展窗口现在同时受真实当前时间和用户冻结 cutoff 约束，并按周期收盘边界对齐；候选分组与最终子窗口均应用相同边界，既避免未来归档请求，也避免检索纳入 cutoff 之后的行情。已有月档缺失时回退原索引范围的行为保留。

## 验证

- 原图诊断使用真实公开索引和官方行情，未读入人工保存位置作为搜索条件：SKHY 从空结果恢复为最高 0.899929，77 个合约最佳片段 >= 0.60；黄金原图识别为 1d。
- 新增 60% 包含边界、稀有度不改变等级、变长包含片段召回、XAU 与 XAUT 区分及不写入截图位置的回归测试。
- 可选原图回归：设置 SCOREBOOK_SCREENSHOT_FIXTURES（内含 skhy、gold 两个原图）和 SCOREBOOK_OCR_EXECUTABLE 后，运行 `cargo test -p scorebook-infrastructure --lib real_toolbar_and_header_geometry -- --ignored --nocapture`。该测试只读图片并使用本机 OCR，不访问数据库。
- 全套隔离库测试 240 通过、0 失败、12 个需外部能力的用例忽略；新增目录类型兼容与目录刷新缓存回归、相关 library/校准测试再次通过。Clippy 全 targets 零告警，依赖边界检查通过。原图 native OCR 专项另行通过。
- 部署后 API/UI 实测记录在本文件后续验收段。

覆盖边界：检索只遍历已发布的公开历史特征，并采用有界候选与真实行情精排；此修复没有宣称完整覆盖币安所有历史，也没有把粗排距离或稀有度当作相似度。
