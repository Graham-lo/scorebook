# 2026-09-11 Mac 复盘与手机更新

- 判断与复盘分别保存当时截图和后续走势截图，每组最多 20 张；单张追加和多选上传共用同一列表，失败可单张重试，移除中的上传不会晚到后复活。
- 复盘草稿保存附件与交易信息，发布时以事务同时保存引用及数据；保留原判断正文与原图，兼容没有新增字段的旧草稿。
- 可选交易信息默认折叠；点击手动输入后填写品种、方向、开平仓时间、数量和单位、杠杆、价格、盈亏、费用等。未完成信息可存草稿，发布前检查必填信息。
- 历史仓位按账户、品种、持仓重叠时间、方向、状态筛选并分页。用户明确选择后加入复盘。后端按归属验证并从账本生成快照，拒绝跨账户引用；交易历史没有提供的杠杆允许明确手动补充。未配置实际交易所凭证，本次没有进行真实账户同步。
- 手机品种菜单约束在可视区域内，随软键盘可视区域变化调整列表高度；搜索框字号 16px，触摸选项至少 44px。SKHY 的窄屏菜单越界已复现并修复；未复现用户原先看到的脚本异常，尚未在用户的实体手机上验证。
- 用户要求的数据清理已执行，生产库只保留其一条原记录及原图；全部新增验证使用隔离库，完成后删除。
